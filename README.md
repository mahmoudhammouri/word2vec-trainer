# Text → Numbers: text representation methods

Interactive teaching pages that show, step by step, how text is turned into vectors.

**Live site:** https://mahmoudhammouri.github.io/word2vec-trainer/

| Page | Method | What you can explore |
|---|---|---|
| `index.html` | Home | Overview and comparison of the four methods |
| `onehot.html` | One-Hot Encoding | building the vocabulary, one-hot vectors, encoding a sentence, limitations |
| `bow.html` | Bag of Words | counting words, document-term matrix, document similarity, what is lost |
| `tfidf.html` | TF-IDF | term frequency, inverse document frequency, keywords, BoW vs TF-IDF |
| `word2vec.html` | Word2Vec | sliding window, Skip-gram & CBOW, training step by step, vector space |

Every page lets you edit the sentences and load example sets in **English or Arabic**.
Add `#3` (or any step number) to a page address to open that step directly, e.g. `tfidf.html#3`.

## Run it
Plain HTML files — no installation, no build, no internet needed. Open `index.html` in a browser,
or host with GitHub Pages: Settings → Pages → Deploy from a branch → `main` / `(root)` → Save.
